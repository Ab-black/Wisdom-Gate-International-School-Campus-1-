# Wisdom Gate International School (Campus 1) - Homepage Preview

Single-page homepage concept for presentation to school management. Static HTML/CSS/JS, no build step, no backend.

## Run
Open `index.html` in a browser, or serve the folder with any static server.

## Where to edit
- Images: every `<img>` in `index.html` uses an illustrative Pexels stock photo. Replace the `src` with the school's own photos (put them in `assets/`).
- Contact details: Contact section and footer in `index.html`. Email and opening hours are placeholders until confirmed by the school.
- Verified from the Google Maps listing: 88 Eligbolo Street, Rumuokoro, Port Harcourt 500102, Rivers, and 0806 416 4465.
- Copy (taglines, descriptions) is proposed marketing copy, not official school wording.
